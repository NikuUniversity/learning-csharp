# Learning C# 🚀

A collection of beginner-friendly C# exercises and mini-projects to build core programming fundamentals — variables, loops, OOP, and more.

## 📌 About

This repo documents my journey learning C# from scratch, covering fundamental concepts through small console projects and exercises as I progress from beginner to intermediate.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/your-username/learning-csharp.git

# Navigate into a project folder
cd learning-csharp/projects/calculator

# Run the project
dotnet run
```
